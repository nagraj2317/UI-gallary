01UI styles

Ten different visual languages. Starter uses Minimal, Business uses Dark Luxe with animation, Pro uses Liquid Glass.

Liquid Glass
Liquid GlassFrosted blur with a bright top edge and deep shadow — looks like real glass. Used in the Pro package.
Glassmorphism
GlassmorphismSemi-transparent panel over a colourful background. Cheaper version of liquid glass.
Neumorphism
NeumorphismSoft extruded shapes — the element looks pressed out of the background. Subtle, works on light or grey.
Claymorphism
ClaymorphismPuffy, rounded, inner shadow — soft 3D like clay. Friendly and modern.
Brutalism
BrutalismHard borders, no rounding, bright colour, hard shadow. Bold and loud.
Minimal / Swiss
Minimal / SwissWhite space, thin type, no decoration. Fastest and cleanest.
Dark Luxe
Dark LuxeDeep background with gold accents — the jewellery theme used across these demos.
Gradient Mesh
Gradient MeshMultiple blurred colour blobs behind content. Modern and colourful.
Soft UI
Soft UILight background, gentle shadow, pastel — calm and premium.
Retro / Vintage
Retro / VintageCream paper, serif type, thin borders. Good for traditional jewellery.

02Buttons — every type

Each button has one job. Using the wrong type confuses the customer.

The main action on a page — Add to cart, Place order.
Second action next to the primary — View details.
Quiet action, no background — Cancel, Skip.
Inline text action — Forgot password, Terms.
Small rounded action or filter — All, Earrings.
One icon only — search, heart, menu. Saves space.
Round button fixed on screen — WhatsApp chat, Add.
Main action + a dropdown for more options.
Shows a spinner while saving — stops double clicks.
Small radius button for dashboards and forms.
Delete, cancel order — red tone so nobody taps by mistake.
Confirm, mark paid — green tone.
Raised button that presses down on click.
Brand-coloured button — Continue with WhatsApp.

What each field is for.

Text inputName, city, address — the basic field.
PasswordHidden characters with an eye toggle.
SearchFilters the product list as you type.
Number / PriceOnly digits, used for price and stock.
TextareaMulti-line — address, notes.
Dropdown (select)Pick one from a list — category, state, courier.
Multi-select chipsPick several — sizes, colours, categories.
Date pickerDelivery date, order date.
CheckboxTick many — 'same as billing address'.
RadioPick exactly one — payment method.
Switch (toggle)On/off — 'out of stock', 'show on site'.
Range sliderPrice filter from–to.
StepperQuantity + and −.
File uploadProduct photos and video.
OTP boxes4 boxes that auto-advance while typing.
